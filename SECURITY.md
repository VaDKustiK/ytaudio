# Security

## Reporting

Please report security vulnerabilities privately to the repository maintainers. Do not include secrets or personal data in public issues.

## Privacy

ytaudio has no account, telemetry, analytics, or hosted service. Network requests are made only to:

- YouTube, through yt-dlp, for requested downloads.
- GitHub releases, for yt-dlp dependency downloads and updates.

The server listens on `127.0.0.1` only. Diagnostics do not intentionally include personal data.
